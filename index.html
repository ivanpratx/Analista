Blueprint de la herramienta de análisis financiero

Explora cada capa: ingesta, KPIs, LLM, datos externos, backend, dashboard y seguridad.

1) Ingesta y parsing
Pipeline de ingesta y parsing de documentos
  • Extracción de PDFs/Excels con fallback OCR para escaneados.
  • Mapeo de secciones (MD&A, ingresos, balance, cash-flow, notas) con heurísticas y embeddings.
  • Normalización de unidades (USD/EUR), fechas y porcentajes; validaciones contables básicas.
  • Metadatos guardados: empresa, período, fuente, confianza OCR.
2) KPIs y scoring
Módulo de KPIs, anomalías y scoring
  • Catálogo de KPIs por sector; cálculo sobre dataset normalizado.
  • Detección de outliers y tendencias QoQ/YoY con thresholds y z-scores.
  • Modelo de scoring configurable: crecimiento, rentabilidad, balance y calidad de earnings.
  • Explicabilidad: KPIs y señales que generan el score.
3) Capa LLM
Prompts/flows LLM para resúmenes y eventos
  • Prompts con citaciones al texto fuente (chunking + retrieval) para evitar alucinaciones.
  • Extracción estructurada (JSON) de riesgos, catalizadores y tono del management.
  • Fact-checking cruzando con KPIs calculados.
4) Datos externos
Integración de fuentes externas
  • Conectores de noticias/finanzas para ratings, estimaciones y calendario de eventos.
  • LLM de navegación/QA para resumir noticias con referencias a URLs y fechas.
  • Normalización y almacenamiento de titulares/eventos con puntaje de relevancia y sentimiento.
5) Backend
Infra backend y data layer
  • Esquema de base de datos: documentos, KPIs, eventos externos, logs.
  • Jobs de ingesta y reprocesado con colas; idempotencia por empresa y período.
  • Audit logs y versionado de prompts/modelos.
6) Frontend
Dashboard y UX de insights
  • Cards para score, KPIs, alertas, catalizadores y timeline de eventos/noticias.
  • Enlaces a párrafos/tablas origen (citaciones) y descarga de reporte.
  • Filtros por período, divisa y sector con estados de carga/errores.
7) Seguridad
Seguridad y compliance
  • Autenticación/autorización y cifrado en tránsito/repouso.
  • Validaciones numéricas y reglas anti-alucinación con respuestas citadas.
  • Monitoreo de costos y límites de APIs externas.
8) Evaluación
Plan de evaluación continua
  • Dataset de referencia con reportes anotados y noticias vinculadas.
  • Métricas: precisión KPIs, recall de eventos, tasa de alucinaciones, latencia.
  • Pruebas de regresión para pipelines y plantillas de prompts.
Tip: sirve index.html con python -m http.server 8000 y abre http://localhost:8000 para navegar.
